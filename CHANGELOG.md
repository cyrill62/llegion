# Changelog

Notable changes to Llegion are listed here. `scripts/bump-version.sh` moves the
entries under **Unreleased** into the new version section when a version is bumped.

## [Unreleased]

## [0.3.0] - 2026-10-26

Improve chats manager
Remove python3 dependency for Devz
Make Launchers icons bigger
Update screenshots

### Changed

- The mock Ollama server is now a Rust example (`cargo run --example mock_ollama -- <port>`) instead of a Python script, so the screenshot scripts and the end-to-end test no longer need Python.
- The HTTPS proxy runs [Ferron](https://ferron.sh) (written in Rust) instead of Caddy, from a generated `ferron.kdl`. The self-signed mode now uses a certificate generated by the app in `<config dir>/tls`. The `caddy_path` setting is replaced by `ferron_path`, so set the binary path again if Ferron is not in `PATH`.
- Terminal UI, Logs tab: `f` (was `c`) shows or hides the proxy's lines.
- Desktop app, Chat: saved chats moved from the tab strip to a left panel, grouped by subjects. Create a subject with **+** next to the title, drag chats onto a subject to move them, and remove empty subjects with ×.
- Desktop app: the Chat subjects panel and the main menu can be shrunk with a toggle button (the menu keeps its icons).
- Desktop app, Settings: *HTTPS proxy* and *API tokens* are merged into one *Security* pane.

### Added

- Launcher: agents are shown as a grid of tiles with their logo on top and the name under it (logos from LobeHub Icons and the Pi / Oh My Pi repositories, MIT); Droid has a lettered badge.
- `scripts/screenshots.ps1`: regenerates the screenshots on Windows.
- Windows: live GPU utilisation and VRAM charts for AMD, Intel and other GPUs not covered by `nvidia-smi`, from the system's GPU performance counters.

## [0.2.0]

### Added

- Save benchmark results to `benchmarks.csv` and reload them at startup, on refresh, and after a benchmark completes.
- Browse saved chats in tabs, with per-chat model settings, rename, delete, and collapsible groups.
- Show Ollama agent launch commands for Claude Code, Codex, OpenCode, Pi, OMP, and other integrations.
- Open the configuration and data folders from Application settings.

### Changed

- Use bundled SQLite for chat history by default, with RocksDB available as an opt-in Cargo feature.
- Warn users on first entry to Chat that saved conversations are unencrypted.
- Keep existing RocksDB chat data when SQLite is selected, so it remains available with the RocksDB feature.
