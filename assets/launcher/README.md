Agent icons shown in the Launcher tab, 192×192 RGBA:

- From [LobeHub Icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-png` 2.5.0, MIT): claude, codex, opencode, hermes, openclaw, copilot, cline.
- `pi.png`: redrawn from the Pi logo (<https://pi.dev/logo-auto.svg>, used by [badlogic/pi-mono](https://github.com/badlogic/pi-mono), MIT).
- `omp.png`: the favicon of [omp.sh](https://omp.sh/), Oh My Pi's site ([can1357/oh-my-pi](https://github.com/can1357/oh-my-pi), MIT), resized to 192×192.

`*-dark.png` / `*-light.png` are the variants for the dark and light themes.
